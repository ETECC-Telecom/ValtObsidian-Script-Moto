## Deploy

Para o Deploy do sistema, basta fazer a build pelo Vite, e em seguida subir ao GitHub para ser automaticamente adicionado ao Vercel. 

Executando a Build:
```bash
npm run build
```

Adicionando ao Git:
```bash
git add .
git commit -m "Versão sendo entregue"
git push origin main
```
