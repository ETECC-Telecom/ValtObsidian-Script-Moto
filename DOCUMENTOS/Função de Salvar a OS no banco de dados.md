Após finalizar a OS e realizar todas as funções possíveis da página, teremos um botão para fechar o projeto. Esse botão irá salvar toda a estrutura da OS no banco de dados. Para que eu não esqueça oque deverá ser feito, vou listar todo o procedimento que essa função irá fazer:

- Salvar a estrutura da OS no banco de dados com toda a estrutura necessária para consulta;
- Validar se informações adicionais foram passadas ao cliente, para sincronizar com a planilha;
- Validar se houve a falta de informação na abertura da OS para sincronizar na planilha;
