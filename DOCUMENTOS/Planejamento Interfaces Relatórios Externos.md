[[Regras de Negócio - Relatórios Externos]]
## Página Lista de Formulário

Essa página poderá ser acessada  através do menu inferior da página Home -> Ferramentas -> **Relatórios Externos**

Nessa página teremos uma listagem de todos os relatório que já foram encaminhados para a planilha externa. Poderemos filtrar por Mês e Categoria. 

Também será necessário um botão de exportar, que ira usar o filtro de pesquisa para gerar um relatório markdown com esses elementos. Essa função servirá para fazer auditoria quando a planilha falha.
